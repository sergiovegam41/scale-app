# Scale · página de descarga

Página de presentación de [Scale](https://github.com/sergiovegam41/Scale), publicada con GitHub Pages: **https://sergiovegam41.github.io/scale-app/**

Los botones de descarga apuntan solos a la última versión publicada en los [releases de Scale](https://github.com/sergiovegam41/Scale/releases). Para eso, cada release debe incluir archivos con estos finales de nombre:

| Archivo | Botón |
|---|---|
| `…-android.apk` | Tablet y teléfono |
| `…-windows-setup.exe` | Computador (si existe, se ofrece primero) |
| `…-windows-portable.zip` | Computador (o como alternativa al instalador) |

Es una sola página estática (`index.html`), sin dependencias.
